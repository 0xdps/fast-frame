### 2. Core Field API Implementation

**New Module: `fastframe.models.fields`**

Implemented field types:
- `Field` (base class with validation, metadata)
- `AutoField` / `BigAutoField` (auto-incrementing PKs)
- `CharField(max_length)` with validation
- `TextField` (unlimited text)
- `IntegerField` / `BigIntegerField`
- `BooleanField` (defaults to False, never null)
- `FloatField`
- `DateField` / `DateTimeField`
- `DateTimeField(auto_now_add=True)` for created_at timestamps
- `DateTimeField(auto_now=True)` for updated_at (requires save() hook - future)

**Field Features:**
- `primary_key`, `unique`, `null`, `blank` constraints
- `default` (Python) and `db_default` (SQL) support
- `choices` for validation and admin dropdowns
- `help_text` for admin form hints
- `verbose_name` (auto-generated or explicit)
- Custom `validators` list
- Extra kwargs passed through to SQLAlchemy

**ModelMeta Metaclass** (`fastframe.models.base.ModelMeta`)
- Processes Field declarations before SQLAlchemy sees them
- Converts fields to `mapped_column()` (migration-compatible)
- Auto-adds `id` primary key if not specified
- Processes `class Meta` options (db_table, ordering, verbose_name, etc.)
- Stores field metadata in `Model._meta["fields"]` for admin introspection
- Calls `__set_name__` to auto-generate verbose_name from field name

**Model Meta Options:**
```python
class Meta:
    db_table = "table_name"
    ordering = ["-created_at"]
    verbose_name = "Singular Name"
    verbose_name_plural = "Plural Name"
    unique_together = [["field1", "field2"]]
    indexes = [{"fields": ["field"], "name": "idx_name"}]
```

**ValidationError Exception**
- Added to `fastframe.models.exceptions`
- Used by field validation hooks

### 3. Backward Compatibility

**Old Syntax Still Works:**
```python
# v0.1/v0.2 style - still valid
class User(Model):
    email: Mapped[str] = mapped_column(String(255), unique=True)
```

**Can Mix Both Styles:**
```python
class Mixed(Model):
    # New style
    name = fields.CharField(max_length=100)
    # Old style
    legacy: Mapped[str] = mapped_column(String(50))
```

### 4. Examples & Dogfooding

**Updated `examples/todo_app/todos/models.py`:**

BEFORE:
```python
class Todo(Model):
    __tablename__ = "todos"
    id: Mapped[int] = mapped_column(primary_key=True, autoincrement=True)
    title: Mapped[str] = mapped_column(String(200))
    done: Mapped[bool] = mapped_column(Boolean, default=False)
    created_at: Mapped[datetime] = mapped_column(DateTime, server_default=func.now())
```

AFTER:
```python
class Todo(Model):
    title = fields.CharField(max_length=200)
    done = fields.BooleanField(default=False)
    created_at = fields.DateTimeField(auto_now_add=True)
    
    class Meta:
        db_table = "todos"
        ordering = ["-created_at"]
        verbose_name = "Todo Item"
        verbose_name_plural = "Todo Items"
```

### Phase 4: Model Validation

**`Model.full_clean()` Hook:**
```python
def full_clean(self):
    """Called before save() to validate all fields."""
    for field_name, field in self._meta["fields"].items():
        value = getattr(self, field_name)
        field.validate(value)
    self.clean()  # Custom model-level validation
```

**`Model.clean()` Hook:**

### 3. Model Validation

**Model.clean() Hook:**
```python
class User(Model):
    age = fields.IntegerField()
    has_driver_license = fields.BooleanField()
    
    def clean(self):
        if self.age < 18 and self.has_driver_license:
            raise ValidationError("Underage drivers not allowed.")
```

**Model.full_clean():**
```python
user = User(name="", age=16, has_driver_license=True)
user.full_clean()  # Validates all fields + calls clean()
# Raises: ValidationError with field-specific errors

user.full_clean(exclude=["name"])  # Skip name validation
```

**Model.save(validate=True):**
```python
tag = Tag(name="this is way too long")
tag.save(validate=True)  # Runs full_clean() before saving
```

**Features:**
- Field-level validation (max_length, choices, blank)
- Model-level validation (clean() hook)
- Skips auto-incrementing PKs (they're generated, not validated)
- Returns dict of field → error message
- ValidationError raised with structured errors

**Tests:** 9 tests covering clean(), full_clean(), field validation

### 4. QuerySet Enhancements

**Field Lookups:**
```python
# Comparisons
Book.objects.filter(price__gte=20, year__lt=2020)

# String matching
Post.objects.filter(title__icontains="python")  # Case-insensitive
Article.objects.filter(slug__startswith="tech-")

# Membership
Tag.objects.filter(name__in=["python", "rust"])

# NULL checks
Comment.objects.filter(deleted_at__isnull=True)

# All supported lookups:
# exact, iexact, contains, icontains
# gt, gte, lt, lte
# in, isnull
# startswith, istartswith, endswith, iendswith
```

**Q Objects (Complex Queries):**
```python
from fastframe.models import Q

# OR
Article.objects.filter(Q(published=True) | Q(featured=True))

# AND (implicit in multiple kwargs, explicit with &)
Book.objects.filter(Q(published=True) & Q(year__gte=2020))

# NOT
Task.objects.filter(~Q(done=True))  # Pending tasks

# Complex
Post.objects.filter(
    (Q(published=True, featured=True) | Q(author="Alice"))
)

# With lookups
Product.objects.filter(Q(price__gte=50))
```

**F Objects (Field References):**
```python
from fastframe.models import F

# Field comparisons
User.objects.filter(karma__gt=F("num_posts"))

# Arithmetic (for updates)
user.karma = F("karma") + 1
user.save()

# Operations: +, -, *, /
Post.objects.update(view_count=F("view_count") + 1)
```

**Implementation:**
- `fastframe.models.query.Q` - Logical query combinators
- `fastframe.models.query.F` - Field references
- `_apply_lookup()` - Translates lookups to SQLAlchemy expressions
- `QuerySet.filter()` enhanced to accept Q objects and field lookups
- Recursive Q.to_sqlalchemy() for complex boolean logic

**Tests:** 22 tests covering Q/F objects, all lookups, edge cases
