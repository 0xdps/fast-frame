# ADR 0001: Record architecture decisions

## Status

Accepted

## Context

FastFrame will make many structural choices (ORM facade, CLI, async strategy, app contract). We need a lightweight record that future contributors can read without archaeology in issues or chat.

## Decision

Use Architecture Decision Records in `adr/`, numbered sequentially, with status and consequences.

## Consequences

- Significant API or architecture changes should add or supersede an ADR.
- README and docs link to the ADR index.
