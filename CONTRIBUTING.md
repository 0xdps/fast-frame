# Contributing to FastFrame

Thank you for your interest in FastFrame. This project is in early stages; conventions will tighten as v0.1 lands.

## Before you code

1. Read [docs/design-principles.md](docs/design-principles.md) and [docs/non-goals.md](docs/non-goals.md).
2. For architectural or API changes, add or update an [ADR](adr/README.md).
3. Keep v0.1 scope small — see [docs/mvp-v0.1.md](docs/mvp-v0.1.md).

## Development setup (when implementation exists)

Instructions will live in [docs/development.md](docs/development.md). Until then, this repo holds documentation and project metadata only.

## Pull requests

- One logical change per PR when possible.
- Update docs and ADRs when behavior or public API changes.
- Follow existing commit message style in the repository history.

## Code of conduct

Be respectful and constructive. Report concerns to repository maintainers.

## Questions

Open a discussion or issue for design questions before large implementations — especially around the ORM facade, app contract, and session lifecycle.
